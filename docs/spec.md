# 3DShape — специфікація v1

iOS-застосунок, який за допомогою LiDAR і камери сканує фігури на столі розміром до 30 см і будує з них 3D-моделі з точними розмірами. Терміни — у [GLOSSARY.md](../GLOSSARY.md), ключові рішення — у [docs/adr](adr/).

## Платформа

- iPhone та iPad з LiDAR, iOS 26+.
- Без LiDAR застосунок не встановлюється (`UIRequiredDeviceCapabilities`); у коді все одно є екран-заглушка «не підтримується».
- Мови інтерфейсу: англійська (основна) і українська, через String Catalog.

## Навігація

Таб-бар із трьома табами: **Сканер**, **Збережені**, **Опції**.

## Сканер

### Етапи Scan Session

```
Ready → Detecting → Scanning ⇄ Paused → Finished → Reconstructing → Review → Saved | Cancelled
```

- **Почати** запускає Scan Session. Застосунок автоматично знаходить Subject на площині столу і будує Bounding Box (до 30 см по кожній стороні); користувач може її підправити.
- **Зупинити** ставить на Pause. **Відновити** продовжує той самий сеанс.
- **Завершити** — окрема дія. Дозволена за будь-якого Coverage; якщо Coverage < 80%, показуємо попередження зі списком Missing Regions.
- **Flip** — необов'язковий додатковий прохід із Subject, покладеним на бік, щоб відсканувати дно.
- Автоматична Pause вмикається при перемиканні табу, переході в фон і втраті трекінгу (тоді ще й підказка «Поверніться до об'єкта»).
- Scan Session живе лише в пам'яті: якщо застосунок вбито під час Scanning, сеанс втрачено.
- Після збереження Scanned Model сеанс продовжити не можна.

### Візуалізація під час сканування

- Камера з наведеною Bounding Box. Відскановані частини Subject позначаються хмарою точок; живих полігонів немає (див. ADR 0001).
- Live Dimensions (висота, ширина, довжина) зі знаком «≈».
- Coverage % у реальному часі.
- Missing Regions: кільце або купол секторів навколо Subject, невідскановані сектори підсвічені, плюс текстова підказка («Не вистачає: зверху ззаду»).

### Реконструкція

- Після «Завершити» сеанс переходить у Reconstructing з індикатором прогресу. Триває хвилини.
- Поки іде реконструкція, новий Scan Session почати не можна.
- Знімки зберігаються на диску до збереження моделі; якщо застосунок закрили, реконструкція перезапускається при наступному запуску.
- Деталізація на пристрої — тільки `.reduced`, налаштування якості немає.

### Review

Model Viewer (див. нижче) із панеллю дій **Калібрувати / Зберегти / Скасувати**. Показує:

- Measured Dimensions; об'єм — лише для Closed Model;
- Integrity %;
- Missing Regions: дірки підсвічені червоним, список із переходом камери до кожної;
- Scale Calibration: користувач вводить один відомий розмір, модель рівномірно перемасштабовується.

## Точність

- Вимога: Measured Dimensions відхиляються від справжніх не більше ніж на **±2 мм або ±1%** (що більше).
- Live Dimensions приблизні, вимога точності на них не поширюється.
- Перевірка — ручний протокол на пристрої з набором Reference Objects, виміряних штангенциркулем: кубик ~5 см, коробка ~15 см, циліндр ~25 см. Сканувати → порівняти Measured Dimensions з еталоном.

## Повнота

- **Coverage** — частка секторів огляду навколо Bounding Box, з яких є кадри. Дно рахується лише після Flip.
- **Integrity** — частка поверхні реконструйованої моделі без дір.
- Модель без Flip — Open Model, тому об'єм для неї не показується.

## Збережені

### Список

- Сортування за датою, нові зверху. Пошуку й синхронізації з iCloud у v1 немає.
- Картка: мініатюра, назва (автоматично «Модель N», можна перейменувати), дата, Measured Dimensions, Integrity, позначка «відкалібровано».
- Натискання на картку відкриває Model Viewer на весь екран.

### Model Viewer

Один компонент для Review і для збережених моделей; різняться лише панелі дій.

- Жести: обертання одним пальцем, масштаб щипком, зсув двома пальцями, подвійний тап — повернення до початкового ракурсу.
- **Показати в AR** через Quick Look.
- Накладки: Measured Dimensions, Bounding Box із підписаними сторонами.
- Перемикачі (за замовчуванням вимкнені): «Підсвітити Missing Regions», «Текстура / сітка».
- Панель дій для збереженої моделі: **Перейменувати / Експорт / Видалити** (з підтвердженням), **Калібрувати** з можливістю скинути до Measured Dimensions.

## Збереження та експорт

- Внутрішній формат: USDZ + метадані (див. ADR 0002).
- Export на вимогу через меню «Поділитися»:

| Формат | Вміст | Одиниці |
|---|---|---|
| USDZ | як є, з текстурою | метри |
| OBJ | `.zip` з `.obj` + `.mtl` + `.png` | метри |
| STL | лише геометрія | **міліметри** |
| PLY | геометрія з кольорами вершин | метри |

- Ім'я файлу: `<назва моделі>_<дата>.<ext>`.

## Опції

- Одиниці: мм (за замовчуванням) / дюйми. Розміри показуються цілими міліметрами (за потреби — сантиметри з одним знаком після коми) або дюймами з двома знаками.
- Формат експорту за замовчуванням.

## Дозволи

Без доступу до камери таб «Сканер» показує заглушку з поясненням і кнопкою «Відкрити Налаштування». Інші таби працюють як звичайно.

## Архітектура

- **MVVM.** Застосунок містить екрани (View), ViewModel-і та зберігання метаданих.
- **`Packages/ScanEngine`** — локальний Swift-пакет: сканування, реконструкція, візуалізація, Coverage / Integrity / Missing Regions, вимірювання, експорт.
- **`Packages/UIComponents`** — локальний Swift-пакет: кнопки, бейджі розмірів, картки моделей, Model Viewer.
- Застосунок залежить від обох пакетів; пакети одне від одного не залежать.
- `ScanEngine` надає застосунку протокол, а не конкретний клас. Поруч є фейкова реалізація, яка програє записаний сеанс і віддає готову модель, — для симулятора, SwiftUI Previews і тестів ViewModel-ів.
- Збережений результат у коді називається `ScannedModel`, щоб не плутати з макросом SwiftData `@Model` і шаром M у MVVM. Шаблонний `Item` замінюється на `ScannedModel`.
