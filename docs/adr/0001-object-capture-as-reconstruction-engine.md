# Object Capture як рушій реконструкції

Для Subject до 30 см головні вимоги — точні розміри та впізнавана форма. Тому ScanEngine будує модель через RealityKit Object Capture (`ObjectCaptureSession` + `PhotogrammetrySession`), а не через сітку ARKit Scene Reconstruction і не через власне злиття глибини LiDAR. Object Capture дає метричний масштаб, текстуру, живу хмару точок, паузу та перевертання. Покриття, Цілісність і Пропущені місця ми рахуємо самі поверх нього.

## Considered Options

- **ARKit Scene Reconstruction (`ARMeshAnchor`)**: відхилено. Сітка з трикутниками по кілька сантиметрів, для предметів на столі форма втрачається.
- **Власний TSDF на Metal із `sceneDepth`**: відхилено. Найкращий контроль над Покриттям, але деталізацію обмежує роздільність LiDAR (256×192), а обсяг роботи значно більший.

## Consequences

- На iOS доступна тільки деталізація `.reduced`, тож налаштування якості в застосунку немає.
- Живі полігони під час сканування недоступні: під час сканування показуємо лише точки, полігони — тільки в Review.
- Реконструкція триває хвилини, а не секунди.
