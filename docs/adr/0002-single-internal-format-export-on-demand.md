# Один внутрішній формат, експорт на вимогу

Scanned Model зберігається в одному внутрішньому форматі: USDZ (рідний вихід Object Capture) плюс метадані. Формати USDZ, OBJ, STL і PLY отримуємо через Export у момент поширення, а не під час збереження. Так у сховищі немає дублікатів, усі формати конвертуються з одного джерела, а новий формат додається без міграції збережених моделей.
